כתב יד לפונט Ktav

לחצו על אות כדי לצייר אותה (עכבר, אצבע או עט), או לצלם אות שכתבתם על נייר.

פונט מכל כתב יד

מצלמים או בוחרים תמונה של כתב יד: מכתב, פתק, מחברת, קיר או תמונה מהאינטרנט. מסמנים את האזור עם הכתב, והאפליקציה מוצאת את השורות והאותיות וקוראת מה כתוב. אתם בודקים ומתקנים, ובוחרים אילו אותיות להכניס. אות שמופיעה כמה פעמים נשמרת ככמה גרסאות, ואותיות שלא הופיעו בכלל מושלמות בסגנון של הכתב.

קריאה חכמה עם Claude (רשות)

בלי זה, האפליקציה מנחשת לבד, והניחוש משתפר ככל שיש יותר אותיות שלכם. עם מפתח API של Anthropic, השורות נשלחות ל-Claude, שקורא כתב יד בעברית ובאנגלית הרבה יותר טוב. המפתח נשמר רק בדפדפן הזה, ונשלחות רק תמונות השורות. כל קריאה עולה כמה סנטים מהחשבון שלכם.

גררו את הפינות כדי לסמן רק את האזור עם כתב היד.

בכל שורה: בודקים שהטקסט בתיבה הוא בדיוק מה שכתוב (כולל רווחים וסימנים), ואז בודקים שמתחת לכל אות מופיע התו הנכון. לחיצה על אות מסמנת אותה לדילוג (למשל אות מכוערת או חתוכה). אפשר גם לשנות את התו בתיבה הקטנה.

א. מדפיסים וכותבים

מדפיסים את הדפים, כותבים כל אות בתוך הריבוע שלה בעט כהה (על הקו הכחול התחתון), ומצלמים כל דף ישר מלמעלה כשכל ארבעת הריבועים השחורים בפינות נראים.

ב. מעלים צילום של דף

בדקו שארבע הנקודות הכתומות יושבות על מרכזי הריבועים השחורים. אפשר לגרור אותן.

התקנה ב-Windows

  1. פותחים את הקובץ ‎.ttf‎ שהורד.
  2. לוחצים "Install" (או קליק ימני ← "Install for all users").
  3. הפונט מופיע ב-Word ובכל תוכנה אחרת לפי השם שבחרתם. תוכנות שהיו פתוחות צריך לפתוח מחדש.

גיבוי

האותיות נשמרות רק בדפדפן הזה. כדי להמשיך במחשב אחר, שמרו קובץ פרויקט.
